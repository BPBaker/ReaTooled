v3.05 - in development
 + Scrub tool: new option "Scrub selected tracks only" (Cmd+click or Option+click on the Scrub button), on by default. While the Scrub tool is chosen, only the selected tracks play when you scrub: press on a selected track to scrub all the selected tracks, or on another track to scrub just that one. Choosing another tool puts REAPER's scrub setting back as it was
 + Left-edge ripple works on its own, without the rest of ReaTooled (for example installed by itself from ReaPack). It only changes your mouse settings for the length of a drag
 # Shuffle mode and Separation mode, installed without the rest of ReaTooled, now say they need ReaTooled set up instead of changing your mouse settings
 # Separation mode: turning it off puts the razor-area drag back exactly as it was, including REAPER's own default ("Move areas"); it could become "No action"
 # Updates: entries in the Actions list for ReaTooled scripts that were never installed (earlier releases listed about 20) are cleaned out
 - Removed three old ReaTooled v2 utilities for backing up, merging and replacing the key map. Set up ReaTooled now merges your shortcuts with ReaTooled's (and backs them up first), and the old scripts could replace your whole key map
 # Updates: the ReaTooled Shortcuts button always shows the version you have, even in a toolbar you changed or one from ReaTooled v2
 # Installation: the Welcome to ReaTooled window comes up within a few seconds of REAPER opening. The ReaTooled Starter could wait up to 30 seconds on macOS. It still waits while one of REAPER's own questions (audio device, plug-in scan) is in front
 # Installation: installing the ReaTooled package again after answering No, or after "Restore settings from a backup", asks again whether to set up ReaTooled. Before, the ReaTooled Starter stayed quiet and setup had to be started from the Actions list
 # Installation: ReaTooled no longer replaces your SWS settings file (S&M.ini). Nothing in it was ReaTooled's, and on a first install it could reset your SWS Resources lists and action counts. Your own SWS settings stay as they are
 # Installation: the Video Editing project template no longer has a render folder from the developer's computer; renders go to each project's own folder
 # Installation: a few settings that only belonged to the developer's computer (recent projects of one script, the update check's own notes) are no longer included
